The Problem

Vikas Automotive Components operated three high-speed stamping and assembly lines coordinated by a mix of Siemens S7-300 and S7-1500 PLCs — some installed as far back as 2009. None of these controllers exposed their diagnostic registers to any centralized system. Maintenance engineers walked the floor with clipboards, manually checking indicators. Bottleneck identification was reactive rather than predictive: engineers learned about cycle-time spikes only when downstream buffers overflowed.

The engineering challenge was not just data collection — it was safe data collection without interrupting live production or modifying validated PLC programs that controlled physical safety-critical sequences.

Our Approach

We deployed a read-only OPC-UA server layer on each PLC rack using Siemens' built-in OPC-UA capability (available in S7-1500 firmware 2.0+) and a lightweight Kepware bridge for the legacy S7-300 units. This approach required zero modification to existing ladder logic — a hard requirement for safety validation continuity.

Edge gateways running our proprietary EdgeLink™ firmware aggregated all 40 OPC-UA endpoints, translating register reads into structured MQTT JSON payloads and publishing them to an AWS IoT Core broker over TLS-secured connections. Data latency from PLC register to cloud database was consistently under 1.2 seconds end-to-end.

A custom React-free web dashboard (built in vanilla JS + Chart.js) displayed per-station cycle times, fault counters, and rolling 8-hour throughput trends — fully accessible, keyboard-navigable, and mobile-compatible for tablet-toting floor supervisors.

Technology Stack

OT Layer

  • Siemens S7-300/1500 PLCs
  • OPC-UA (built-in + Kepware)
  • EdgeLink™ edge gateway units
  • Industrial Ethernet (PROFINET)

IT/Cloud Layer

  • AWS IoT Core (MQTT/TLS)
  • AWS Timestream (time-series DB)
  • Vanilla JS + Chart.js dashboard
  • AWS Lambda alert triggers

Results

Within 8 weeks of live operation, the real-time dashboard revealed a recurring 340ms cycle-time spike at Station 7 — a pneumatic gripper with a slow retract sequence that had been absorbing buffer slack invisibly for over a year. A 2-hour mechanical adjustment eliminated the spike, directly contributing to a sustained 14% improvement in overall line throughput.

Manual floor-check rounds decreased by 90% as supervisors shifted to exception-based management: the system generates alerts, they investigate alerts. Unscheduled downtime on the monitored lines dropped 22% in the 6 months post-commissioning.
